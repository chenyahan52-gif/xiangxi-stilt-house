# 湘西吊脚楼 · 手势交互网页

这是一个可直接用 VS Code 打开的前端小项目，包含深色金色 UI、Three.js 3D 模型、摄像头手势识别、展品切换、粒子效果和可开关的合成氛围音。

## 1. 项目文件

- `index.html`：网页结构
- `style.css`：深色金色界面样式
- `app.js`：Three.js 场景、建筑模型、摄像头与手势交互

## 2. 在 VS Code 运行

1. 解压 `xiangxi_stilt_house.zip` 到一个文件夹。
2. 打开 VS Code，点击 **文件 → 打开文件夹**，选择解压后的 `xiangxi_stilt_house` 文件夹。
3. 在 VS Code 扩展商店安装 **Live Server**（如果尚未安装）。
4. 在左侧资源管理器中右键 `index.html`，选择 **Open with Live Server**。
5. 浏览器打开后，点击左侧 **启动手势识别**，并在浏览器弹窗中允许摄像头权限。

> 摄像头通常要求网页运行在 `localhost` 或 HTTPS 环境。不要直接双击 `index.html` 用 `file://` 打开。

## 3. 交互方式

- 鼠标拖动 3D 视口：旋转模型
- 鼠标滚轮：缩放
- 视口底部“重置视角”：回到初始视角
- 张开手掌并缓慢移动：旋转当前模型
- 张开手掌快速横向移动：切换吊脚楼 / 斗拱 / 花窗
- 握拳：重置视角并触发金色闪光反馈
- 点击“山间夜曲”：打开/关闭由 Web Audio 合成的柔和氛围音
- 点击“停止手势识别”：关闭摄像头

## 4. 预期成功标志

- 页面右侧出现 3D 木构建筑，背景有细微金色粒子。
- 摄像头允许后，左侧预览框显示实时画面。
- 检测到手时，预览框会绘制金色骨架线。
- 进行手势时，左侧连击数字增加，展品标题与编号更新。

## 5. 常见问题

- **摄像头启动失败**：确认使用 Live Server 地址（一般为 `http://127.0.0.1:5500`），并在浏览器地址栏左侧的站点权限中允许摄像头。
- **页面空白或 3D 模型不显示**：检查网络连接，Three.js 和 MediaPipe 通过 jsDelivr CDN 加载；按 `F12` 打开开发者工具查看 Console 报错。
- **模型没响应手势**：光线要足够、手掌完整进入画面；手势识别依赖浏览器从 CDN 下载 MediaPipe 资源。
- **声音没有播放**：浏览器通常要求先点击按钮才能启动音频；确认设备音量未静音。

## 6. 技术说明

无需 npm 安装，也无需构建步骤。Three.js 通过 `index.html` 中的 import map 映射模块名称，OrbitControls 使用 `three/addons/` 映射；MediaPipe Hands 通过普通 script 加载。因此首次运行需要联网。摄像头图像由浏览器本地送入 MediaPipe 进行识别，不会由本项目主动上传到服务器。

这是课程演示级原型；不同摄像头、光线和浏览器会影响识别效果。快速挥手和张掌旋转的阈值可在 `app.js` 的 `onResults()` 中调整。
